# V1.3 Hybrid 变更记录

相对于 V1.2.1：
- P02下承托框、P03方柱、P04底座、P05活动压块、P06旋钮保持原几何；P05/P06数量各从8减至4。
- P01替换为带两螺栓局部对位接口的上承载框，取消上夹的活动压块、导槽及旋钮。
- 新增P07四孔尼龙安装板×4；5.2mm圆角窗口允许约±0.8mm名义位置差；普通自由螺母和OD9背垫圈随螺杆对位。
- 安装板局部径向±10mm、竖向±18mm补偿，不改变主框层间位置。孔组到板边的未知距离仍受有限适配范围约束。
- 原馈线桥与新安装板相交问题已经消除；桥移向中央，保留每路独立软绑带与下行路线。
- 新增薄孔位模板、真实P07首件排版与独立T03接口快检块。
- 已检查装配预装尼龙螺钉、螺母、垫圈、软垫后的完整PCB组件落入，包含另三路完整示例天线；目标下夹退开2mm。
- 净打印件18个；净螺钉40颗，详见新BOM，不沿用旧20颗的数量。
- 4张正式3MF仅含几何，不含切片、支撑和G-code。升级仅需2张、6个新件。

没有执行实际打印或载荷、蠕变、RF测试；没有额定强度或一次必装成功保证。
